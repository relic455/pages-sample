Getting Started
===============

This page is a short tour of common elements you can reuse in your docs.

Quick start
-----------

1. Edit files under ``source/``.
2. Add new pages to the ``toctree`` in ``index.rst``.
3. Build the HTML output.

.. code-block:: console

   make html

What this page demonstrates
---------------------------

* Headings and sections
* Numbered lists
* Code blocks
* Admonitions

.. note::

   This project uses Sphinx defaults, so you can start with reStructuredText
   before adding extensions.
