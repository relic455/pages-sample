# FAQ

## Where do I add new pages?

Create a new `.md` file under `source/` and add it to `index.md`.

## How do I preview the site?

Run `make html` and open `build/html/index.html` in a browser.

## Can I mix Markdown and reStructuredText?

Yes. With `myst-parser`, you can include reStructuredText directives when
needed.
