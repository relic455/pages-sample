How-to
======

This page collects short, task-focused notes.

Add a new page
--------------

1. Create a ``.rst`` file under ``source/``.
2. Add it to the ``toctree`` in ``index.rst``.
3. Build the HTML output for Site B.

.. code-block:: console

   make html

Use an admonition
-----------------

.. tip::

   Keep filenames lowercase with hyphens for consistency.
