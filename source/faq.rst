FAQ
===

Common questions for this sample site.

Where do I add new pages?
  Create a new ``.rst`` file under ``source/`` and add it to ``index.rst``.

How do I preview the site?
  Run ``make html`` and open ``build/html/index.html`` in a browser.

Can I mix Markdown and reStructuredText?
  Yes, but you need an extension such as ``myst-parser`` in ``conf.py``.
